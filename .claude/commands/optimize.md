# /optimize Command

## Mission (Sứ mệnh)

Analyze and improve code structure, database queries, and basic performance. (Phân tích và cải thiện cấu trúc code, câu lệnh truy vấn CSDL và hiệu năng cơ bản).

---

## 1. Identify Issue (Xác định Vấn đề)
- N+1 Query problem? (Bị lỗi N+1 truy vấn?)
- Missing database index? (Thiếu chỉ mục CSDL?)
- Messy code? (Code bị rườm rà, khó đọc?)

## 2. Proposed Improvements (Đề xuất Cải tiến)
- SQL optimization (Tối ưu truy vấn).
- Refactoring for Clean Code (Tái cấu trúc cho Clean Code).
- Applying Design Patterns (Áp dụng các Design Pattern hợp lý để ghi điểm bảo vệ).

## 3. Output Format (Định dạng Đầu ra)
- Vấn đề hiện tại.
- Đoạn code / Cấu trúc cũ.
- Cách tối ưu.
- Lợi ích về mặt học thuật/thực tiễn.
