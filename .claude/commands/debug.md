# /debug Command

## Mission (Sứ mệnh)

Find the root cause of local development issues. (Tìm nguyên nhân gốc rễ của các lỗi xảy ra trong quá trình phát triển trên máy cá nhân).

---

## Phase 1: Define the Problem (Xác định Vấn đề)
- Lỗi gì đang xảy ra? (Error message là gì?)
- Xảy ra khi thực hiện hành động nào?

## Phase 2: Analyze Logs & Code (Phân tích)
- Đọc Terminal / Console log.
- Kiểm tra lại logic code ở tầng Service / Controller tương ứng.
- Kiểm tra xem Database có bị sai kiểu dữ liệu không.

## Phase 3: Root Cause & Fix (Nguyên nhân & Khắc phục)
- Trả lời câu hỏi: Tại sao lại lỗi?
- Đề xuất cách sửa trực tiếp vào file.

---

## Rules (Quy tắc)
Focus on solving the bug quickly and ensuring it doesn't break other graduation project features. (Tập trung sửa lỗi nhanh và đảm bảo không làm hỏng các tính năng khác để kịp tiến độ bảo vệ).
