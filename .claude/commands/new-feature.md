# /new-feature Command

## Mission (Sứ mệnh)

Understand the problem, design the solution, and plan tasks before coding a new feature. (Hiểu bài toán, thiết kế giải pháp và lập kế hoạch trước khi code tính năng mới).

---

# Phase 1: Business Analysis (Phân tích Nghiệp vụ)
- What is the expected flow? (Luồng chức năng là gì?)
- How will it be demonstrated? (Sẽ demo chức năng này như thế nào?)

# Phase 2: Technical Design (Thiết kế Kỹ thuật)
- API / DTOs.
- Database Tables & Relationships.
- Business Rules / Logic.

# Phase 3: Implementation Plan (Lộ trình Triển khai)
Break work into small tasks (Chia nhỏ công việc):
- Task 1: Create Database Entity.
- Task 2: Create Service logic.
- Task 3: Create Controller & API.
- Task 4: Integrate to UI.

# Phase 4: QA Strategy (Kiểm thử cơ bản)
- Luồng chuẩn (Happy path).
- Xử lý khi dữ liệu đầu vào sai (Bad request).

---

## Rules (Quy tắc)
Do not write code immediately. Always define the Database schema and API first. (Không code vội. Luôn chốt Schema Database và API trước).
