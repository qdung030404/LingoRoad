# /design Command

## Mission (Sứ mệnh)

Create a formal technical design before major changes. (Tạo thiết kế kỹ thuật chuẩn mực trước khi code các tính năng lớn).

---

## 1. Context (Ngữ cảnh)
- Business requirements. (Yêu cầu nghiệp vụ/đề bài).

## 2. Proposed Design (Thiết kế Đề xuất)
- Domain / Module structure. (Cấu trúc phân hệ).
- Database Entity-Relationship. (Thiết kế thực thể - E-R).
- API Endpoints. (Thiết kế API).

## 3. Alternatives (So sánh Giải pháp)
- Tại sao chọn cách thiết kế này thay vì cách khác? (Why this approach?)

## 4. Testing Plan (Kiểm thử)
- API Tests (Kiểm thử API cơ bản qua Postman / Swagger).
- Edge cases (Các trường hợp ngoại lệ).

---

## Rules (Các Quy tắc)
Focus on Clean Code and Clean Architecture. (Tập trung vào Clean Code và Clean Architecture).
Make it easy to explain to the grading committee. (Thiết kế phải dễ dàng giải thích trước hội đồng chấm thi).
