**Trọng tâm:** Bài toán tối ưu hóa + hạ tầng kỹ thuật để hiện thực hóa toàn bộ hệ thống.

1. **Learning Path Optimization**
    - Mô hình hóa bài toán lập lịch học như bài toán tối ưu tổ hợp
    - Thuật toán Greedy, Dynamic Programming
    - Reinforcement Learning (DQN/PPO) để sinh lộ trình tối thiểu hóa thời gian đạt mục tiêu
2. **Công nghệ nền tảng**
    - Python: thư viện ML (PyTorch/TensorFlow cho các mô hình ở mảng 1 & 2), framework backend (FastAPI/Flask)
    - ReactJS: kiến trúc frontend, quản lý state, kết nối API
    - PostgreSQL: thiết kế schema lưu trữ dữ liệu người học, lịch sử luyện tập, kết quả đánh giá — tối ưu cho truy vấn phục vụ mô hình

**Đầu ra:** Tài liệu mô tả bài toán tối ưu (input/output/constraints), so sánh 3 phương pháp (Greedy vs DP vs RL) về độ chính xác/chi phí tính toán, và đề xuất kiến trúc hệ thống (Python + React + PostgreSQL) tích hợp với 2 mảng còn lại.
